# Homelab 
This repo holds my homelab config.

## Setup
1. Install Debian
2. [Install Docker](https://docs.docker.com/engine/install/debian/)
3. [Set up GitHub SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)
4. git clone this directory
5. Run `docker compose up -d`
6. Run `sudo apt install network-manager`
